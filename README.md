# Olist E-Commerce Analytics

## Project Overview

This project analyzes the Olist Brazilian E-Commerce dataset to identify
sales performance, customer behavior, product performance, delivery
performance, customer satisfaction, and seller performance.

The project covers the complete data analytics workflow, starting from
data quality checking and SQL analysis in PostgreSQL to data modeling
and interactive dashboard development in Power BI.

The main objective is to transform raw e-commerce data into actionable
business insights that can support decision-making related to sales,
customers, logistics, products, and sellers.
